# MiSTer Control releases

Downloads for MiSTer Control, the second screen and controller for the MiSTer FPGA.

- Releases: the `mister-control-<version>-armv7.zip` under Releases.
- `release.json`: the current version, download URL and checksum. The app reads this to check for updates.
- `db.json`: an update_all downloader database. Add it to `downloader.ini` to install and update through update_all.
- `catalog.json`: the install catalog shown in the app.

The application source is not published.
